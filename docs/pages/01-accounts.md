# 账户与资金（tab-accounts）

> 代码位置：`static/index.html` 的 `tab-accounts`、`loadAccounts / renderAcctPanel / renderAcctCards / renderAcctEquity`；
> 后端 `AccountService`、`AccountMapper`、`AccountDailyMapper`。

## 1. 这页回答什么（不回答什么）

**回答**

- 现在有几个启用中的账户，各自最新净值、现金、持仓市值是多少？
- 全部账户合计赚了多少：已实现多少、浮动多少、总盈亏多少？
- 哪个账户在赚钱、哪个在拖后腿，卖出胜率和持仓结构如何？
- 新增账户后余额为什么立刻有数？

**不回答**

- 不回答区间收益、最大回撤、计划内外胜率差、亏损原因——这些在「统计总览」。
- 不回答单只标的赚亏与走势——去「标的分析」。
- 不做汇率换算：CNY / USD / HKD 汇总时按数字直接相加。

## 2. 数据来源与查询条件

| 数据块 | 接口或表 | 过滤条件 | 何时刷新 |
| --- | --- | --- | --- |
| 顶部 8 个 KPI、账户卡片 | `GET /accounts` → `t_account` + `t_account_daily` + `t_trade` + `t_position` | 仅 `active = 1` 的账户，按 `id` 升序；**无日期、无全局账户过滤** | 进入账户页、新建账户成功后 |
| 「最新资金快照」提示 | `AccountSummary.snapshotDate` | 每个账户 `t_account_daily` 最新一条 `trade_date`，页面取这些日期的最大值 | 同上 |
| 账户净值对比 | `GET /accounts/equity?from=2000-01-01&to=今天` → `t_account_daily` | 全部启用账户；每账户按 `trade_date` 升序；无点的账户也返回空数组 | 同上 |
| 新增账户 | `POST /accounts` → `t_account`，初始资金 > 0 时再 upsert `t_account_daily` | 名称必填；`initialCapital >= 0`；`currency` 空则 CNY | 点「创建账户」后 |
| 全局账户下拉框 | 前端 `localStorage` 中的当前账户 ID | 不发起请求 | 切换时只重绘卡片高亮；本页统计不变，其它页按该账户重载 |
| 账户卡片点击 | 前端事件 | — | 立即切换全局账户并高亮 |

**关键口径**：全局账户下拉框在本页**只负责高亮对应账户卡片**，不裁剪 KPI 与曲线；本页始终展示全部启用账户的合计。停用账户不出现，但其历史数据仍参与「统计总览」的全部账户统计。

## 3. 字段口径

### 3.1 顶部 8 个 KPI（对全部启用账户求和）

| 字段 | 计算口径 | 来源 | 正常范围/参考 | 异常含义 |
| --- | --- | --- | --- | --- |
| 总权益 | `Σ equity`，即各账户最新净值之和 | `t_account_daily` 最新一条 | ≥ 0；应约等于现金 + 持仓市值 | 0 且提示「还没有资金快照」= 从未复盘且初始资金为 0 |
| 现金 | `Σ cash`；副标题 `cash / equity × 100%` | `t_account_daily` 最新一条 | 0~100%；占比越低仓位越重 | 现金占比过高=资金闲置；`equity=0` 时副标题显示「暂无快照」 |
| 持仓市值 | `Σ marketValue`，单账户 `marketValue = equity − cash`；副标题 `marketValue / equity × 100%` 为仓位 | 由最新净值与现金相减，**不按持仓重新估值** | 0~100% | 为负=现金快照大于权益，通常两边口径录错 |
| 总盈亏 | `Σ totalPnl`，单账户 `totalPnl = realizedPnl + floatingPnl` | 成交汇总 + 持仓快照 | 可正可负 | 与净值涨跌不一致时，先查浮动盈亏是否缺快照 |
| 已实现盈亏 | `Σ realizedPnl`，只取卖出流水；**无日期过滤，是账户全部历史** | `t_trade`，`side='SELL'` 的 `realized_pnl` 求和 | 可正可负 | 与统计页区间值不同是正常的，区间会裁日期 |
| 浮动盈亏 | `Σ (最新快照收盘价 − 加权成本) × 持仓数量`；无最新快照的持仓不参与 | `t_position` JOIN `t_position_daily` 每标的最后一条 | 可正可负 | 只覆盖有快照的持仓，不是实时行情；缺快照会被低估 |
| 卖出胜率 | 优先按卖出笔数加权：`Σ(winRate × sellCount) / Σ sellCount`；全部账户卖出数为 0 时退化为有值账户的简单平均；无任何值则「—」 | 各账户 `winRate`（0~1）+ `sellCount` | 0~100%，页面保留 1 位小数 | 「—」= 没有卖出记录，不等于 0% 胜率 |
| 持仓只数 | `Σ positionCount`，`positionCount` 为 `t_position` 行数 | `t_position` | ≥ 0 | 0=当前无持仓；与「持仓市值」同时为 0 才表示确实空仓 |

### 3.2 账户卡片

| 字段 | 计算口径 | 来源 | 正常范围/参考 | 异常含义 |
| --- | --- | --- | --- | --- |
| 账户名 / 券商 | `name`，`broker` 可空 | `t_account` | — | 名称为空会在新建时被拒绝 |
| 权益 | `equity`，该账户最新净值 | `t_account_daily` | ≥ 0 | 0=无快照 |
| 总盈亏 | `realizedPnl + floatingPnl` | 成交 + 持仓快照 | 可正可负 | — |
| 收益率 | `(equity − initialCapital) / initialCapital × 100`；百分数本身，保留 2 位；`initialCapital=0` 时为 null → 页面「—」 | `AccountService.summary` | 可正可负 | 分母为 0 时没有收益率，不是 0% |
| 现金 / 持仓市值 | 最新 `cash`；`equity − cash` | `t_account_daily` | 均 ≥ 0 | 持仓市值为负=快照不一致 |
| 已实现 / 浮动 | 同 KPI，单账户维度 | `t_trade` / `t_position_daily` | 可正可负 | — |
| 卖出胜率 | `winCount / sellCount`，0~1，页面乘以 100 保留 1 位 | `t_trade` 卖出且 `realized_pnl` 非空 | 0~100% | 「—」= `sellCount=0` |
| 持仓 / 成交 | `positionCount` / `tradeCount`；成交是全部历史笔数（含买入） | `t_position` / `t_trade` | 均 ≥ 0 | 成交多但持仓少=换手高或已清仓 |
| 高亮 | 卡片 `id` 等于全局账户下拉框当前值 | 前端比较 | — | 高亮不代表筛选，只是提示切到哪个账户 |

### 3.3 账户净值对比图

| 字段 | 计算口径 | 来源 | 正常范围/参考 | 异常含义 |
| --- | --- | --- | --- | --- |
| 账户线 | 每账户一条线；以**各自区间第一个净值**为 100 归一化 | `/accounts/equity` | 100 为起点 | 无点的账户不画，图例里也不会出现 |
| 图例涨跌 | 归一化序列末值 / 首值 − 1，显示 2 位百分数 | 前端 `indexLineChart` | 可正可负 | 只反映形态，不是绝对收益金额 |
| 悬停原始值 | `num(equity)` + 「元」 | `t_account_daily.equity` | — | 金额未做汇率换算 |
| 区间范围 | 固定 `2000-01-01 ~ 今天`，不受统计页日期影响 | `loadAccounts` | — | 账户页没有日期控件 |

### 3.4 提示与空态

| 位置 | 文案/表现 | 触发条件 | 读法 |
| --- | --- | --- | --- |
| 顶部快照提示 | 「最新资金快照 YYYY-MM-DD」 | 至少一个账户有 `snapshotDate` | 取各账户快照日期的最大值，不代表每个账户都更新到这一天 |
| 顶部快照提示 | 「还没有资金快照」 | 所有账户都无快照 | 先去每日复盘提交现金余额 |
| 账户列表 | 「还没有账户，先在下方创建一个。」 | `GET /accounts` 返回空 | 可能账户都被停用，不一定是没建过 |
| 净值图 | 「还没有账户净值快照」 | 所有账户净值点为空 | 快照或日期范围（本页固定 2000-01-01 起）导致 |
| KPI 副标题 | 「暂无快照」 | 对应账户 `equity` 为 0 | 该账户不参与占比和合计的有效性 |

### 3.5 新增账户表单

| 字段 | 口径 | 正常范围/参考 | 异常含义 |
| --- | --- | --- | --- |
| 账户名称 | 去首尾空格后必填 | 非空 | 空 → 后端报「账户名称不能为空」 |
| 券商 / 渠道 | 可空，去空格 | — | — |
| 币种 | CNY / USD / HKD，空按 CNY；仅备注，不换汇 | 三选一 | 汇总时不同币种直接相加 |
| 初始资金 | 必填，`>= 0`，默认 0 | ≥ 0 | 负数前端与后端都会拒绝 |
| 备注 | 可空 | — | — |
| 开户快照 | 初始资金 > 0 时写当天一条 `equity = cash = 初始资金`，备注「开户初始资金」 | 当天可见 | 之后同一天复盘会用 upsert 覆盖该条 |

## 4. 分析步骤

1. 点左侧「账户」，先看「最新资金快照」日期；日期不是最近交易日，说明复盘没更新。
2. 看 3 个规模 KPI：**总权益 → 现金 → 持仓市值**，记住现金占比与仓位百分比。
3. 看「总盈亏 → 已实现盈亏 → 浮动盈亏」：判断赚的钱是落袋的还是账面的。
4. 看「卖出胜率」样本是否足够（副标题有卖出笔数），再逐张账户卡片比较**收益率、已实现、浮动、胜率、持仓/成交**。
5. 看「账户净值对比」：各线是否同向、谁长期在 100 下方；需要绝对回撤去统计页。
6. 点表现差的账户卡片，全局切换到该账户；再点顶部「收益统计 →」进入统计总览拆原因。
7. 新增账户时填初始资金，创建后回本页确认卡片余额与净值线已出现。

## 5. 带数字的案例

> **以下为示例数据。**

- 账户 A：初始资金 300,000.00，权益 301,200.00，现金 50,000.00，持仓市值 251,200.00，已实现 +1,240.00，浮动 −40.00，总盈亏 +1,200.00，收益率 +0.40%，卖出 12 笔胜 7 笔（58.3%），持仓 3 只。
- 账户 B：初始资金 200,000.00，权益 190,800.00，现金 40,000.00，持仓市值 150,800.00，已实现 −3,090.00，浮动 −6,110.00，总盈亏 −9,200.00，收益率 −4.60%，卖出 6 笔胜 2 笔（33.3%），持仓 2 只。
- 页面提示最新快照 2026-11-04。

**判断链**

1. **现象**：总权益 492,000.00，现金 90,000.00（18.3%），持仓市值 402,000.00（81.7%）；总盈亏 −8,000.00，其中已实现 −1,850.00、浮动 −6,150.00；加权卖出胜率 9/18 = 50.0%。
2. **结论**：仓位 81.7% 偏重；亏损主要不在已实现，而在浮亏（−6,150.00 远大于 −1,850.00），且账户 B 的净值线在 95.40，明显跑输 A（100.40）。
3. **该点哪里**：点账户 B 卡片切换全局账户 → 点「收益统计 →」→ 在统计页同一区间看到区间收益 −3.2%、最大回撤 8.4%、计划内胜率 55.6%、计划外胜率 20.0% → 再点 KPI「已实现盈利 / 亏损」进入亏损原因。
4. **该改什么**：先把 B 的浮亏标的按最新快照核对并设置止盈止损；把计划外「追高」交易降为零；仓位从 81.7% 降一档后再观察净值曲线是否回到 100 上方。

## 6. 判读表

| 现象 | 结论 | 动作 |
| --- | --- | --- |
| 页面提示「还没有资金快照」，权益与现金为 0 | 账户从未提交复盘，且开户时初始资金为 0 | 去「每日复盘」提交当天现金余额；或核对是否该账户未启用 |
| 现金占比 < 10%，仓位 > 90% | 接近满仓，回撤会被放大 | 看统计页最大回撤；结合计划内外胜率决定是否降仓 |
| 已实现为正、浮动为大额负数 | 利润没落袋，浮盈在回吐 | 切到该账户 → 标的分析，检查止盈纪律与持仓成本 |
| 收益率高但卖出胜率低 | 靠少数大赚覆盖多数小亏 | 看统计页盈亏比与最大单笔亏损是否可承受 |
| 某账户净值线长期在 100 下方 | 该账户执行更差，或用途是试错仓 | 切到该账户看计划内外胜率差与亏损原因 |
| 持仓市值 > 权益（为负） | 现金快照大于权益，录入口径冲突 | 核对当天复盘的现金与净值，重新提交覆盖 |
| 持仓只数 > 0 但持仓市值为 0 | 快照里的现金等于权益，或持仓快照成本/价格缺失 | 补当天持仓快照；检查 `t_position_daily` |
| 多币种账户合计后金额异常大 | USD/HKD 未换汇，按数字直接相加 | 分开看单账户，不要直接读合计 |

## 7. 数据前提与常见问题

- 「总权益 / 现金」「持仓市值」都来自**最新一次每日复盘**的资金快照；没有快照就是 0，不是实时券商余额。
- 新建账户只有填写**大于 0** 的初始资金才写当天快照；填 0 时卡片权益仍为 0。
- 同一天重复提交复盘会 upsert 覆盖当天的 `equity/cash`，不会新增重复行。
- 本页 KPI 是**全部启用账户**合计，不受右上角全局账户下拉框裁剪；下拉框只高亮卡片。停用账户不显示。
- 本页「已实现盈亏」是**全部历史**，统计页是**区间**；日期区间不是「全部」时两页数字不同是正常的。
- 浮动盈亏只覆盖有**最新持仓快照**的标的，缺快照按不参与处理，因此可能小于实际浮亏/浮盈。
- 卖出胜率按笔数加权；账户间卖出笔数差距很大时，简单平均会被小样本账户带偏，页面已优先加权。
- 账户净值对比图把每条线首点归一到 100，适合比形态，不适合比金额和回撤。
- 不同币种没有汇率换算；总权益、总盈亏是原币数字直接相加。
