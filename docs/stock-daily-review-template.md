# 每日复盘模板

> 用法：收盘后 15 分钟内填完，**填不出来的空着，不要事后补编**。
> 原则：只记录事实和当时理由，不做预测、不写"如果当初……"。
> 每个交易日一份，文件名建议 `2026-11-05.md`，按月放一个文件夹。
> 不知道怎么填，先看 [填写示例（模拟数据）](./stock-daily-review-example.md)。

---

- [ ] 已看过持仓股的公告（业绩预告 / 减持 / 诉讼 / 停复牌）

## 六、一句话总结与明日计划

## 附二：填写示例

```text
日期：2026-11-05

【盘前计划】
若 600XXX 跌破 18.20 → 卖出全部（止损位，逻辑证伪），已挂条件单。

【今日操作】
卖出 600XXX，18.15 × 500 股，计划内。
理由：跌破止损位，原判断"毛利率回升"被三季报证伪。

【持仓快照】
总仓位 12%，最大潜在亏损 720 元（占资金 1.4%），在预算内。

【纪律自检】
违背 0 次。

【一句话】
止损执行到位，但昨天的入场理由是"看到板块在涨"，本身就不可证伪，问题出在买入前而不是卖出时。
```

---

> 模板只是骨架。真正起作用的是两件事：**每笔都写得出可证伪的理由**，以及**每月把"违背次数"统计出来**。
