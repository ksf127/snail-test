## 一、第一阶段：打好基础（1~3 个月）

原图写 1~2 个月，偏乐观：估值和财报这两块，1~2 个月只能入门，读不懂三张表之间的勾稽关系。

### 1.1 市场语言（了解即可，不要当预测工具）

- K 线、均线、成交量：知道它们描述了什么，**不要相信形态能预测未来**。
- 技术指标（MACD、KDJ、RSI）：全部是历史价格的再加工，天然滞后。作为择时辅助，不作为买入理由。

### 1.2 基本面（这条才是主线）

- 市盈率 PE、市净率 PB、ROE：判断「贵不贵、赚不赚钱」的入口。
- **单看 PE/PB 不够**，要结合三件事：
  - 行业属性：银行 5 倍 PE 和科技 50 倍 PE 不可比；
  - 盈利质量：经营现金流是否跟得上净利润；
  - 负债水平：有息负债 / 净资产，以及短期偿债压力。
- 会读三张表的最低要求：

| 报表 | 看什么 |
|---|---|
| 利润表 | 收入与毛利率的**趋势**，而不是只看单季利润 |
| 资产负债表 | 有息负债规模；应收账款增速是否远超收入增速 |
| 现金流量表 | 经营现金流净额是否持续为正；与净利润的比值长期是否低于 1 |

### 1.3 风险管理（比选股重要）

- **单笔最大亏损 ≤ 总资金 1%~2%**，由此反推每笔能买多少，而不是先想买多少再想止损。
- 总仓位上限：新手阶段建议不超过 30%，分散到 3~5 只不同行业。
- 止损、止盈都要事先写下来。注意：机械止损在震荡市会被反复打脸，止损位应放在「逻辑被证伪」的位置，而不是固定的百分比。

举例：总资金 10 万，单笔风险预算 1% 即 1000 元。若计划在 20 元买入、18 元止损（每股亏 2 元），则最多买 500 股。**是风险预算决定仓位，不是先决定仓位再想止损。**

### 1.4 学习资料怎么选

| 类型 | 建议 | 说明 |
|---|---|---|
| 书 | 《股票作手回忆录》 | 当交易心理与投机史读，**不是方法论教材** |
| 书 | 《日本蜡烛图技术》 | 技术分析入门，知道形态叫什么即可，不要当圣杯 |
| 书 | 一本会计学入门 / 财报分析 | 优先级高于上面两本，能看懂三张表才有基本面判断力 |
| 视频 | 有完整方法论、讲风险、不荐股 | **筛选标准**：凡是引导你加群、买软件、跟着买某只票的，直接关掉 |

判断一个内容源值不值得看，看三点：它讲不讲风险、讲不讲自己错在哪、有没有最终导向某个收费产品。

## 二、第二阶段：模拟实战（3~6 个月）

原图写 2~3 个月，覆盖不到不同市场状态。A 股一轮完整牛熊通常 3~5 年，模拟期至少要跨过一段上涨和一段下跌。

### 2.1 模拟盘能练什么、不能练什么

| 能练 | 不能练 |
|---|---|
| 下单流程、交易软件操作 | 真实亏损带来的情绪压力 |
| 记录买卖理由、复盘习惯 | 滑点、流动性、挂单排队 |
| 验证自己的选股逻辑是否自洽 | 仓位被套住时的心理承受力 |

**结论：模拟盘只能练流程和记录，练不了心态。不要把模拟盘收益当作「我行了」的证据。**

### 2.2 这个阶段唯一必须养成的习惯

每笔交易记录四件事，缺一不可：

1. **买入理由**：一句话，必须可证伪。例如「毛利率连续两季回升」，而不是「感觉要涨」；
2. **卖出条件**：什么情况下认错离场；
3. **实际结果**：盈亏、持有天数；
4. **复盘结论**：理由对了但亏了？理由错了但赚了？——后者更危险。

每个月统计一次：胜率、盈亏比、最大回撤。**盈亏比比胜率重要**：胜率 70%、每次赚 1% 亏 5% 的体系，长期是亏的。

## 三、第三阶段：小资金实盘（准入标准）

原图用「模拟盘稳定盈利 3 个月」当门槛，这是最需要改的一条。替换为下面三条**同时满足**：

1. **资金**：总资金的 5%~10%，且是三年内不用的闲钱；
2. **风险预算**：单笔最大亏损 ≤ 总资金 1%~2%，连续亏损 6 笔后强制停手复盘；
3. **样本量**：完整跑够 50~100 笔交易，期间最大回撤不超过事先设定的阈值（例如 10%）。

三条都满足，再谈加仓；任何一条不满足就退回上一阶段。

**这一阶段的目标不是赚钱，是「不亏大钱 + 验证自己的交易体系能不能在真实情绪下执行」。**

## 四、第四阶段：工具（默认用 App，别提前上框架）

### 4.1 第一层：默认方案，同花顺 / 东方财富就够

学习阶段不需要任何额外工具，两个免费 App 已经覆盖 90% 的需求：

| 需求 | 对应功能 |
|---|---|
| 模拟盘练流程 | 同花顺模拟炒股、东方财富模拟交易 |
| 看基本面 | F10 财务数据、行业对比 |
| 复盘与记录 | 自选股分组、交易记录、条件单提醒 |

券商自带 App（涨乐财富通、e 海通财等）同样够用，用哪个顺手就用哪个。

### 4.2 第二层：什么时候才需要额外工具

只有出现下面这些**具体需求**时，工具才有意义：

| 需求 | 才考虑 | 说明 |
|---|---|---|
| 自己拉数据做统计，验证某个条件的历史胜率 | akshare | Python 数据接口库，把数据拉下来自己算，这才叫验证 |
| 把规则写成代码跑历史回测 | vn.py / backtrader | 学习曲线陡，**必须先有成型策略**再谈框架 |
| 看盘效率 | 无需额外工具 | go-stock 这类与同花顺功能重叠，装了只增加「我在做研究」的错觉 |
| 写复盘、整理信息 | 任意 AI 助手 | 只用来归纳自己写的记录，**不要用来选股** |

**工具解决的是「验证效率」，不是「胜率」。** 没有成型方法之前上工具，等于用工程复杂度掩盖策略缺失。

### 4.3 程序员的正确用法：用 akshare 验证自己的逻辑

这是本文最想强调的一节。程序员的优势不是会写代码，而是**能把自己的交易假设变成可证伪的实验**。
正确姿势是：复盘里写下一条条件 → 用历史数据统计它到底有没有用。

#### 第一步：把「感觉」写成可量化的条件

不合格的写法：「找业绩好的低估值股」。
合格的写法必须同时具备四要素：

| 要素 | 例子 |
|---|---|
| 可量化 | ROE > 15%，且经营现金流净额 / 净利润 > 1 |
| 可观测时点 | 用「T 日收盘后已披露」的财报，即公告日 ≤ T |
| 动作明确 | T+1 开盘买入，持有 N 个交易日后收盘卖出 |
| 对照基准 | 同期沪深 300 收益，或同池随机买入的收益 |

写成一句话：

> **在公告日当天，若近四个季度 ROE > 15% 且经营现金流净额/净利润 > 1，则 T+1 开盘买入，持有 20 个交易日，统计相对沪深 300 的超额收益。**

#### 第二步：拉数据

```python
import akshare as ak

# 1) 行情：注意复权，否则分红送股会把收益算错
px = ak.stock_zh_a_hist(symbol="000001", period="daily",
                        start_date="20190101", end_date="20241231",
                        adjust="qfq")

# 2) 财务指标：注意接口返回的是「报告期」，还需要「公告日」才能避免未来函数
fin = ak.stock_financial_analysis_indicator(symbol="000001", start_year="2019")

# 3) 基准：沪深 300 指数
bench = ak.stock_zh_index_daily(symbol="sh000300")
```

接口名以 akshare 官方文档为准（版本更新较快）。数据源与字段要自己先抽查几条，别默认它是对的。

#### 第三步：算，而且必须算对

核心逻辑只有四行，难的是不犯错：

```python
# 信号日：公告日（不是报告期！用报告期就是未来函数）
signal_day = fin["公告日"]

# 买入价：信号日之后的第一个开盘价
buy_price = px.loc[px["日期"] > signal_day, "开盘"].iloc[0]

# 卖出价：持有 N 个交易日后的收盘价
sell_price = px.loc[px["日期"] > signal_day, "收盘"].iloc[N]

# 超额收益：必须减去基准，否则牛市里什么策略都"有效"
excess = (sell_price / buy_price - 1) - (bench_n / bench_0 - 1)
```

统计输出至少四个数，缺一个结论都不可信：

| 指标 | 为什么必须看 |
|---|---|
| 命中次数 | 少于 30 次的样本量，胜率没有统计意义 |
| 胜率 | 单看胜率会被「小赚多次、大亏一次」骗 |
| 平均超额收益 / 盈亏比 | 决定这套逻辑到底赚不赚钱 |
| 最大回撤 | 决定你能不能扛住 |

#### 第四步：排除四个常见陷阱

绝大多数「回测有效、实盘失效」都栽在这四处：

1. **未来函数**：用报告期而不是公告日，等于提前知道了财报——最常见的自欺。
2. **幸存者偏差**：只统计现在还活着的股票，退市的、被 ST 的都被排除，收益率会被系统性高估。
3. **复权与成本**：不复权会把分红送股算成暴跌；不算佣金与印花税，短线策略的超额收益经常直接被吃光。
4. **过拟合**：把参数调到历史最优（比如「持有 17 天」），换一段时间就失效。至少要分两段样本：前段调参、后段验证。

#### 结论

跑完这套流程，通常只会得到两个结果之一：

- 条件**没有超额收益**——这是好事，你用几百行代码省下了真金白银的学费；
- 条件**有超额收益**——先别高兴，换时间段、换股票池、加上交易成本再跑一遍，还成立才叫成立。

**工具的价值在于证伪你的想法，不在于生成你的想法。**

## 五、每天、每周、每月怎么执行

核心原则：**把决策移到盘前和盘后，盘中只执行。** 上班族在盘中做决策，最终一定会变成冲动交易。

### 5.1 工作日：三段式日程

| 时段 | 时长 | 做什么 | 不做什么 |
|---|---|---|---|
| 08:40–09:10 | 20 分钟 | 看持仓公告；检查昨晚写好的卖出条件；写下今天的「若 X 则 Y」计划；把条件单挂好 | 不临时找新标的；不刷股吧与荐股群 |
| 09:30–15:00 | 0 分钟 | 不看。只在 10:00 与 14:30 各看一次是否触发提醒 | 不在午休下单；不边写代码边看盘；不追涨杀跌 |
| 15:00–15:20 | 20 分钟 | 记录当天交易（理由 / 执行 / 偏差）；更新持仓成本与止盈止损位 | 不因为当天亏损临时改计划 |
| 20:30–21:00 | 30 分钟 | 学习期：读财报或书的一章；模拟期：复盘当天模拟单；实盘期：只看持仓公告 | 工作日不选股、不调参数 |

三个阶段每天的重点不同：

| 阶段 | 每天的主战场 |
|---|---|
| 打基础 | 20:30 那一档：一天一章书或一份财报，做笔记而不是划重点 |
| 模拟实战 | 15:00 那一档：每笔模拟单必须写满四栏（理由 / 卖出条件 / 结果 / 复盘） |
| 小资金实盘 | 08:40 那一档：计划在开盘前写完，盘中只执行条件单 |

每天的具体填写用 [每日复盘模板](./stock-daily-review-template.md)：盘前填计划、盘后填操作与纪律自检。忙的时候用它的 7 分钟极简版。

### 5.2 周末：1~2 小时做三件事

1. **统计**：本周胜率、盈亏比、最大回撤（超过 30 笔后直接用 `GET /stats/overview`，见 5.6）；
2. **归类**：每笔交易标成「计划内」或「计划外」——计划外的交易即使赚钱也要单独计数，那是运气不是体系；
3. **更新观察池**：总数不超过 20 只，逻辑失效的剔出去。

**参数优化只放在周末做。** 盘中改规则等于边开车边修发动机，改出来的规则也无法回测验证。

### 5.3 每月：一次月度复盘

- 本月收益 vs 沪深 300；
- 纪律违背次数（计划外交易、临时改止损、听消息下单）；
- 决定下月仓位上限：连亏三个月先降到最低档，而不是加大投入。

### 5.4 三条红线

- 上班时间不盯盘；
- 亏损当天不加仓摊薄成本；
- 盘中不改已经写下的计划。

### 5.5 忙的时候：10 分钟最小版

| 时间 | 做什么 |
|---|---|
| 早上 3 分钟 | 看有没有影响持仓的公告（业绩预告、减持、诉讼、停复牌） |
| 收盘后 7 分钟 | 记录当天操作与理由，一句话总结有没有破纪律 |

日程可以简化，**记录不能中断**。记录一断，复盘就没有素材，整个学习循环直接失效——这也是大多数人「学了半年没长进」的真实原因。

### 5.6 记录放在哪里：Excel 起步，超过 30 笔迁到 trade-journal

**先说清楚一件事：** [每日复盘模板](./stock-daily-review-template.md) 确实只适合一天，这是有意的——它是一张「当天的表」，
不是数据库。单日记录回答不了「这个月胜率多少、最大回撤多深、我最常犯哪条纪律」，
这些问题的答案不在任何一天里，而在**多天数据的差值与累计**里。

所以不要把模板当成数据库用（在同一个 sheet 里往下堆日期，两周后公式就会乱）。
真正需要长期记录的是三类数据，缺一类就算不出完整指标：

| 数据类别 | 内容 | 缺了会怎样 |
|---|---|---|
| 流水 | 每一笔成交（价格、数量、费用、是否计划内） | 胜率、盈亏比无从谈起 |
| 快照 | 每天的持仓明细与账户净值 | **最大回撤算不出来**（这是最常被忽略的一条） |
| 文本 + 明细 | 当日复盘文字、纪律违背逐条 | 只能看到结果，看不到原因 |

**分阶段选择工具：**

| 交易笔数 | 用什么 | 原因 |
|---|---|---|
| 前 20 个交易日 | Excel / 飞书表格 + 本模板 | 摩擦最低，重点是养成「每天写」的习惯，不是追求统计精度 |
| 超过 30 笔，或开始分批建仓 | `trade-journal` 服务 | 加权成本、两边费用、每日净值这些公式手算必错，而错的方向通常固定（胜率偏高） |
| 任何时候的手机速记 | 备忘录 / Excel | 只当草稿，晚上再录进系统，不要两份数据长期并存 |

完整说明见 [trade-journal 系统文档](./trade-journal-guide.md)（含字段表、接口示例、部署与统计口径）。

#### trade-journal 的数据模型（8 张表）

日复盘在这个系统里只是**入口**，不是主表。真正的统计都从流水和序列推出来：

| 表 | 作用 | 关键点 |
|---|---|---|
| `t_trade_plan` | 盘前计划「若 X 则 Y」 | 不允许删除，否则无法统计「计划了多少、执行了几条」 |
| `t_trade` | 成交流水 | 所有统计的唯一事实来源；卖出时写入 `realized_pnl` |
| `t_position` | 当前持仓 | 加权成本**已含买入费用**，卖出直接用它算盈亏 |
| `t_position_daily` | 每日持仓快照 | 一天一只一行，画仓位曲线用 |
| `t_account_daily` | 每日净值 | 一天一行；**最大回撤只能从这条序列算** |
| `t_daily_review` | 复盘文字 | 一天一条，重复提交视为修改 |
| `t_discipline_violation` | 纪律违背明细 | 按条记录，月度统计才有依据 |
| `t_sector_daily` | 板块行情参考 | 银行板块用中证银行 399986；用来分清「选错股」还是「踩错方向」 |

`t_sector_daily` 与个人记录无关，是**只读参考**：V2 脚本里预置的 9 个交易日是示例点位
（`note` 标了「示例」），真实行情用 `sector-import` profile 一次性导入，
导入器会先清掉示例行再写真实值，见 [trade-journal 文档 7.5](./trade-journal-guide.md#75-替换真实行情板块参考数据)。

一处口径说明：买入费用摊进成本价、卖出费用在卖出时扣减，
所以 `已实现盈亏 = 卖出金额 - 卖出费用 - 加权成本 × 数量`，两边费用都被计入，不需要额外字段区分。

#### 接口一览

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/plans` | 盘前写计划 |
| GET | `/plans?planDate=2026-11-05` | 查当天计划 |
| POST | `/plans/{id}/cancel` | 条件未触发，取消计划 |
| POST | `/trades` | 记一笔成交（系统自动维护持仓与盈亏） |
| GET | `/trades?from=…&to=…` | 区间成交明细 |
| GET | `/trades/positions` | 当前持仓 |
| POST | `/reviews` | 提交当日复盘（文字 + 持仓收盘价 + 违背项） |
| GET | `/reviews/{date}` | 查某日复盘 |
| GET | `/stats/overview?from=…&to=…` | 一次拿到胜率、盈亏比、回撤、违背次数 |
| GET | `/stats/trades` `/stats/drawdown` `/stats/discipline` | 单项细查 |

`POST /reviews` 里 `equity` 可以不传：不传时系统按 `现金 + Σ(收盘价 × 持仓数量)` 自动算净值。
**不要手填净值**——手填最常见的错误就是漏掉现金，回撤会因此算错。

#### 启动方式

```bash
# 先建库（表由 Flyway 在启动时自动执行 db/migration/V1__init.sql）
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS trade_journal DEFAULT CHARSET utf8mb4"

# 启动服务，默认 8205 端口；账号密码可用环境变量覆盖
mvn -pl trade-journal -am spring-boot:run
```

数据落在 MySQL，不在 Excel 里。这样做的直接好处是：周末的「胜率、盈亏比、最大回撤」
不再需要现场套公式，一次 `GET /stats/overview` 就取回来，而且每次口径完全一致。

## 六、关于「副业」的提醒

原图这部分基本正确：前期大概率亏钱、时间投入大（9:30–15:00 加复盘）、心态要求高、本金少时收益绝对值低。

补充四条原图漏掉的：

1. **交易成本会吃掉短线收益**：印花税、佣金、过户费叠加，频繁交易时这是一笔可观支出，先算成本再算策略。
2. **信息源纪律**：散户最大的亏损来源往往不是不会看 K 线，而是听消息、追热点、进荐股群。把「不打听消息」写进纪律。
3. **禁止杠杆**：融资融券、场外配资、期权，新手阶段直接列入禁止清单。
4. **幸存者偏差**：你看到的成功案例都是活下来的人，亏光离场的人不发帖。

### 一句话定位

**先学、再模拟、最后小资金实盘。前半年不要想赚钱，目标是「不亏大钱 + 建立自己的交易体系」。**

但也要清楚：A 股长期年化并不高，散户长期跑赢指数很难。把它当「理财 + 学习」是合理的，当「稳定副业收入」基本不现实——按副业时薪算，绝大多数人不如把时间投在本职工作上。

## 八、常见错误清单

| 错误 | 后果 |
|---|---|
| 用模拟盘盈利证明自己能实盘 | 真实下跌时拿不住，前面赚的一次亏回去 |
| 把 K 线形态当买入理由 | 只看到「符合形态」的样本，忽略了失败形态 |
| 用报告期数据回测 | 未来函数，回测收益虚高 |
| 只统计还活着的股票 | 幸存者偏差，收益被系统性高估 |
| 不扣交易成本 | 短线策略的超额收益经常被成本吃光 |
| 听消息、追热点 | 买入时点永远是消息链条的末端 |
| 亏损后加仓摊薄成本 | 单笔风险失控，违背 1%~2% 风险预算 |
| 用杠杆 | 波动被放大，回撤可能直接触发强制平仓 |

## 九、术语速查

| 术语 | 含义 | 容易误解的地方 |
|---|---|---|
| PE（市盈率） | 股价 / 每股收益 | 不同行业不可直接比；周期股在盈利高点时 PE 反而低 |
| PB（市净率） | 股价 / 每股净资产 | 重资产行业参考价值高，轻资产行业意义有限 |
| ROE（净资产收益率） | 净利润 / 净资产 | 高 ROE 可能来自高杠杆，要看负债结构 |
| 经营现金流净额 | 经营活动实际收到的现金净额 | 长期低于净利润，说明利润没有变成现金 |
| 回撤 | 从最高点跌下来的幅度 | 决定你扛不扛得住，比收益率更重要 |
| 盈亏比 | 平均盈利 / 平均亏损 | 与胜率一起看才有意义 |
| 滑点 | 下单价与成交价的差 | 模拟盘里通常没有，实盘小盘股非常明显 |
| 未来函数 | 用了当时还不可能知道的信息 | 回测收益虚高的头号原因 |
| 幸存者偏差 | 只统计活到今天的样本 | 让你系统性高估历史收益 |
| 复权 | 把分红送股折算回连续价格 | 不复权会在除权日出现假暴跌 |
